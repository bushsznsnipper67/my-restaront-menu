# 🍽️ Yummy Restaurant Menu

Welcome to **Yummy Restaurant!** 😋

A simple and attractive restaurant menu webpage built using **HTML and CSS**. It displays delicious food items, their descriptions, prices, and Add to Cart buttons.

## ✨ Features

- 🍕 **Food Menu:** Displays three food items.
- 🖼️ **Food Images:** Shows an image for each dish.
- 📝 **Food Descriptions:** Lists the ingredients of each item.
- 💲 **Prices:** Displays the price of every dish.
- 🛒 **Add to Cart Buttons:** Includes buttons for customers to select food.
- 📱 **Responsive Viewport:** Includes a viewport setting for mobile-friendly display.

## 🛠️ Technologies Used

- **HTML5** – Structures the webpage and displays the menu.
- **CSS3** – Styles the menu, food cards, buttons, and layout.
- **Emojis** – Make the menu more fun and attractive.

## 🚀 How to Run the Project

1. Download or clone this project to your computer.
2. Make sure all the image files are in the correct folder.
3. Open the project folder in your code editor.
4. Open `index.html` in your web browser.
5. Enjoy exploring the Yummy Restaurant Menu! 🎉

## 🎯 Project Goal

The goal of this project is to learn the basics of HTML and CSS by creating a restaurant menu webpage with food images, descriptions, prices, and interactive-looking buttons.
